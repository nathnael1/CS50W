# Django Twitter Clone (X Clone)

A social media application built using Django that mimics the functionality of X (formerly known as Twitter). Users can post tweets, like posts, follow other users, and engage with social content.

## Features

- **User Authentication**: Sign up, log in, and log out functionality for users.
- **Tweet Posting**: Users can create and publish posts (tweets) with text content.
- **Like System**: Users can like and unlike posts.
- **Follow/Unfollow System**: Users can follow and unfollow other users.
- **Profile Page**: Each user has a profile page showing their tweets and followers.
- **Feed**: A feed that displays the latest posts from the users the logged-in user follows.
- **Responsive Design**: Mobile-first responsive design for optimal experience across devices.
